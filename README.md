# vibe-
自己尝试一个可交互界面

后端使用 Node.js 原生 ES Module，提供留资与 CMS 读取接口。支持 SQLite 本地开发和 PostgreSQL 生产存储。

本地启动、数据库初始化、接口契约、测试及待定部署事项见 [后端使用说明](docs/backend.md)。

首次运行可按 [本地启动说明](本地启动说明.md) 操作；本轮检查及修复见 [整体验收记录](docs/acceptance-2026-10-17.md)。

第 6 步「真实素材接入」标记为 **等素材，暂不启用**，现有程序化开场保持不变。后续素材规格见 [视频开场接入约定](docs/media-intro.md)。
