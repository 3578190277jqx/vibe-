# Aether 三维交互网站与后端接口

基于 Three.js 与原生 JavaScript 的交互网站实践，包含滚动驱动三维场景、移动布局、留资表单和 Node.js 后端接口。

**完整实现位于 [feat/backend-api 分支](https://github.com/3578190277jqx/vibe-/tree/feat/backend-api)**。main 保留早期前端版本，开发分支未合并。

## 重点实现

- 三维场景与滚动交互、移动布局和性能降档。
- Node.js 留资和 CMS 文案读取接口。
- 唯一索引去重、滚动窗口限流及静态文件白名单。
- SQLite 本地开发与 PostgreSQL 存储适配。
