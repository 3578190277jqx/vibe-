## 实测发现并修复

1. 带独立 BEGIN/COMMIT 的初始化 SQL 不可直接交给多连接池执行。现使用 `sql.reserve()` 固定连接，失败时显式回滚后释放。
2. PostgreSQL 驱动结果数组包含额外原型，现由适配层转为普通数组，使无文案结果与 SQLite 行为一致。
3. RLS 拒绝插入会中止整个事务；测试按整个事务失败断言，避免错误地在中止事务上继续提交。
