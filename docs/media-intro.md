# 第 6 步：真实素材接入

状态：**等素材，暂不启用**。

当前沿用现有程序化开场。此步骤仅记录后续接入约定，收到用户提供的文件路径后再实施。

## 暂缓原因

本次产品取舍以国内用户通过微信打开为前提，优先控制首屏加载成本。移动端视频滚动寻址所需的全关键帧编码或帧序列会增加素材体积；现有程序化开场无需加载三维素材，保留其视觉特点。

## 后续品牌片规格

| 项目 | 约定 |
| --- | --- |
| 时长 | 不超过 8 秒 |
| 视频编码 | libx264，全关键帧 |
| 编码参数 | `-g 1 -crf 20 -movflags +faststart -an` |
| 桌面源 | 宽度 1920px，独立文件 |
| 移动源 | 宽度 1280px，独立文件 |
| 播放属性 | 必须设置 `muted` 和 `playsinline` |
| 未就绪兜底 | `readyState < 2` 时回退到 poster |
| 滚动控制 | 滚动进度驱动视频时间，滚动停止时视频暂停 |
| 世界衔接 | 视频段结束后进入三维世界 |

启用时由用户提供桌面视频、移动视频及 poster 的实际文件路径。收到素材后再验证微信内置浏览器、移动端寻址和加载体积，不提前启用视频入口。
