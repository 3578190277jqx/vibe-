# 七章场景布局

章节布局集中在 `world-layout.js`，三件产品的几何构成及旋转在 `world-products.js`，`world.js` 负责材质注册、场景摆放和渲染。均为原生 ES Module，继续使用本地 three.js 0.160.0，无额外依赖或构建流程。

| 02 | shards | Shards | 14, 2.2, 4 | 12.5, 4.5, -9 |

前五个镜头保持原样。新第六章使用原门户的镜头位置，原门户顺延到第七章。新增两段摄像机间距各约 23.7；新第六章摄像机到目标约 15.1，第七章约 20.5。门户目标向右错开，避免它在手机产品镜头中遮住陈列。

始终使用 `CatmullRomCurve3.getPoint(p)`。每个章节中心进度为 `i/6`，指示器和顶栏跳转统一使用 `chapterProgress(i)`，不再写死 `/5`。

## 文字窗口

所有窗口由 `[i/(N-1) - 0.125, i/(N-1) + 0.125]` 生成，宽度固定 0.25。

| 章节 | 中心 | 窗口（近似值） |
| --- | --- | --- |
| 01 | 0 | -0.125 ～ 0.125 |
| 02 | 1/6 | 0.041667 ～ 0.291667 |
| 03 | 2/6 | 0.208333 ～ 0.458333 |
| 04 | 3/6 | 0.375 ～ 0.625 |
| 05 | 4/6 | 0.541667 ～ 0.791667 |
| 06 | 5/6 | 0.708333 ～ 0.958333 |
| 07 | 1 | 0.875 ～ 1.125 |

相邻窗口重叠 1/12（约 0.083333），用于交叉溶解。HTML 的 `data-i` 是位置；`data-key` 是内容身份。新增 `products` 不改变已有 `portal` 的 key，CMS 继续按 key 匹配，不能根据 CMS 返回顺序重排镜头。

七章间隔较原六章更短，因此淡入覆盖窗口的前半、淡出覆盖后半。相邻章节中点的两层文字各约 0.259 不透明度，避免沿用旧曲线时两层均为 0.583 的明显叠印。每章中心仍完全可见；首章保留直接可见的开场逻辑。指示器按最近的章节中心选择唯一激活项，并同步 `aria-current="step"`，不再按各层文字的不透明度独立激活。

## 三件产品

- 便携音箱：圆柱主体、端盖、环形格栅、半环提手与方形指示灯。
- 香氛瓶：八棱柱瓶身、收口肩部、瓶颈、方形瓶盖与标签几何体。
- 桌面灯：圆柱底座与灯杆、锥台灯罩、圆盘发光面、球形灯泡。

三个组有独立旋转速度和小幅漂浮；减少动态效果模式下，新产品保持静止。材质沿用现有冷蓝及紫色，全部通过 `aetherMaterial()` 注册到 `MATERIALS`，并设 `amp: 0`、`pulseScale: 0`，避免组合零件受脉冲影响而分离。

桌面产品放在文案右侧；手机收紧三件模型的横向间距、缩小至 0.48，并抬高位置，保留文字和按钮空间。

## 静态托管与验证

发布时需连同两个新增模块一起保留原路径。Node 后端的静态白名单已允许这两条精确路径，没有开放任意源码目录。

`npm test` 覆盖七章锚点采样、窗口宽度和中心、镜头间距、产品组合与旋转，以及两个新增模块的 HTTP 可达性。浏览器另检查 1280×800 和 375×812 下七章跳转、章节文字对齐、三件产品在视口内、最后一章到达、重播及正常动态模式下的独立旋转。

本步未修改后端 CMS 种子或已有数据库记录。将来启用动态文案时，按 `products` 添加内容，按 `portal` 更新展示编号即可；不要覆盖运营修改或迁移稳定 key。
