# 序场：视觉与排版优化

2026-10-17。沿用现有冷色三维世界、系统字体与七章内容，集中改善构图和阅读层级。

## 页面表现

- 桌面采用左侧文字、右侧主体的构图，共用页边距对齐品牌、正文和页脚。首屏标题放大，其余章节保留较轻的阅读节奏。
- 手机继续底部排版，主体在投影中上移；产品章沿用已有的上方三件陈列。表单继续全宽，输入与按钮高度至少 48px。
- 每章中心仅显示该章主体，章间保留相邻物体渐变交接，避免后续场景闯入首屏。星尘和地面参照继续存在。
- 品牌标记改为原生 SVG 取景框，标签改为斜线分隔的轻量文字，首屏「开始探索」可直接跳到下一章。
- 导航保留七章及无障碍标签；手机视觉圆点为 6px、激活为 8px，触摸区域仍为 44×44px。悬停不会将手机圆点拉成长条。
- 桌面高度不超过 700px 时收紧字号和留白，过长文案可在文字栏内滚动。隐藏章节设置 inert 和 aria-hidden，避免键盘触达不可见操作。
- 日常隐藏 FPS 数字，自动降档时仍显示「已自动降档」。

## 实现约束

摄像机路径、ANCHORS、AT、WINDOWS、getPoint() 参数采样、89°→55° 开场视场角不变。构图使用 camera.setViewOffset()；产品章的水平偏移减小，给三个模型和导航留空间。首轮保留模型尺寸；第二轮的晶面细分与陈列比例调整见下。

world-layout.js 的 createChapterFocus() 按章节进度设置可见性及材质透明度。同一组内共享材质只计算一次，始终基于初始不透明度，不累乘。渐变时暂停主体深度写入，到达完整显示时恢复原值；加色材质保留原有深度策略。普通场景材质允许透明混合，粒子及门户圆盘着色器也同步使用 uOpacity，防止渐变时残留。

辉光、曝光、配色、脉冲及性能降档基线不变。没有新增依赖、网络字体或媒体文件；favicon 为内联 SVG。第 6 步仍为「等素材，暂不启用」，程序化开场继续使用。

- 手机回归另覆盖 375×568、812×375，确认圆点触摸区域、长文案滚动、全宽表单、粒子预算及真实提交。手机非激活圆点 hover 仍为 6×6。
- 桌面与 375px 的 CMS 非阻塞开场、按 key 匹配、纯文本渲染、字段兜底与超时回退通过。
- 桌面与 375px 的表单新增、重复、422→429、蜜罐、断网、503、非 JSON、忙碌状态和超时后重试通过。

## 第二轮：中段场景与产品陈列（2026-10-18）

逐章截图发现碎晶细分过高而接近圆球、群集近排过大压字，以及手机产品偏小且陈列拥挤。本轮恢复碎晶的八面体/四面体晶面，glow 调至 1.05、shade 调至 0.52；相同冷蓝配色及全局曝光、辉光参数继续沿用。

群集只调整根组的陈列比例和倾斜，保留局部方块几何、间距、数量、波动公式与 pulseScale:0。桌面根组比例为 0.44，手机基础比例为 0.40，另按屏幕空间收紧；桌面投影略向右，为文字留间距。

手机三件产品的基础比例由 0.48 提高为 0.72，横向间距由 1.8 提高为 2.4，重新安排垂直位置；短屏再按高度缩小、上移。桌面按宽高比约束产品和群集陈列，初始化与 resize 同步更新。质量预算仍按初始化时的设备选择，不在 resize 中重建粒子或方块。

触摸滑动此前也会写入 mx/my，造成模型跟随手指偏移；现在只接收桌面 mouse 指针，减少动态效果模式忽略视差。切到手机宽度时清除残留偏移，避免桌面鼠标位置影响手机构图。

本轮截图在 .local/round2-actual/。几何边界检查对群集与产品采样 0～180 秒共 37 个旋转/波动姿态；它检查包围盒与文字、顶栏和视口的间距，不把辉光光晕计作实体边界。极矮屏仍以文字栏可滚动、表单可操作为验收目标，不能据此声称任意屏幕上模型与文字都完全分区。

已执行以下第二轮检查：

- 1440×900 的普通动画及减少动态效果模式；1024×768、900×600、861×600、375×812、375×667、320×568、768×1024。每组对群集和产品分别检查 37 个姿态，实体边界与文字、顶栏及视口均保留至少 12px 水平/文字间距和 4px 顶栏间距。
- 在同一页面中连续切换 1440→375→1280→320→768→900→1440 宽度，检查两组模型仍在视口内，手机布局清除桌面残留视差，不靠重新加载修复布局。
- 触摸事件不会写入鼠标视差；桌面普通模式的 mouse 事件仍可产生视差，手机和减少动态效果模式保持静止。该行为已先复现原版失败，再验证修复。
- 七章文字边界、唯一指示器、章节隐藏状态、产品入镜、重播及顶栏跳转回归通过。Node 内置测试仍为 38 项。
