# 序场：视觉与排版优化

2026-10-17。沿用现有冷色三维世界、系统字体与七章内容，集中改善构图和阅读层级。

## 页面表现

- 桌面采用左侧文字、右侧主体的构图，共用页边距对齐品牌、正文和页脚。首屏标题放大，其余章节保留较轻的阅读节奏。
- 手机继续底部排版，主体在投影中上移；产品章沿用已有的上方三件陈列。表单继续全宽，输入与按钮高度至少 48px。
- 每章中心仅显示该章主体，章间保留相邻物体渐变交接，避免后续场景闯入首屏。星尘和地面参照继续存在。
- 品牌标记改为原生 SVG 取景框，标签改为斜线分隔的轻量文字，首屏「开始探索」可直接跳到下一章。
- 导航保留七章及无障碍标签；手机视觉圆点为 6px、激活为 8px，触摸区域仍为 44×44px。悬停不会将手机圆点拉成长条。
- 桌面高度不超过 700px 时收紧字号和留白，过长文案可在文字栏内滚动。隐藏章节设置 inert 和 aria-hidden，避免键盘触达不可见操作。
- 日常隐藏 FPS 数字，自动降档时仍显示「已自动降档」。

## 实现约束

摄像机路径、ANCHORS、AT、WINDOWS、getPoint() 参数采样、89°→55° 开场视场角及现有模型尺寸不变。构图使用 camera.setViewOffset()；产品章的水平偏移减小，给三个模型和导航留空间。

world-layout.js 的 createChapterFocus() 按章节进度设置可见性及材质透明度。同一组内共享材质只计算一次，始终基于初始不透明度，不累乘。渐变时暂停主体深度写入，到达完整显示时恢复原值；加色材质保留原有深度策略。普通场景材质允许透明混合，粒子及门户圆盘着色器也同步使用 uOpacity，防止渐变时残留。

辉光、曝光、配色、脉冲及性能降档基线不变。没有新增依赖、网络字体或媒体文件；favicon 为内联 SVG。第 6 步仍为「等素材，暂不启用」，程序化开场继续使用。

## 本轮验证

- Node 内置测试 38 项通过，新增章节渐变、共享材质去重及深度状态恢复测试。
- Chrome 实际渲染检查 1440×900、1365×768、1024×768、900×600、1280×600、375×812、375×667、375×400：逐章确认文字边界、场景隔离、唯一活动指示器、隐藏章节 inert、无横向溢出，以及「开始探索」跳转。
- 手机回归另覆盖 375×568、812×375，确认圆点触摸区域、长文案滚动、全宽表单、粒子预算及真实提交。手机非激活圆点 hover 仍为 6×6。
- 桌面与 375px 的 CMS 非阻塞开场、按 key 匹配、纯文本渲染、字段兜底与超时回退通过。
- 桌面与 375px 的表单新增、重复、422→429、蜜罐、断网、503、非 JSON、忙碌状态和超时后重试通过。
- 产品完整入镜、独立旋转、重播及顶栏跳转通过；90 帧降档、后台时钟、减少动态效果、WebGL 中文提示及后期处理失败后直接渲染回归通过。
